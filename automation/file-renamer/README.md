# ⚙️ File Renamer Automation

> A simple Python automation tool for renaming files in a folder using a consistent naming pattern.

## 🎯 Problem

Renaming many files manually can be repetitive and time-consuming.

This project automates the process by applying a consistent prefix to supported files while allowing the user to review the changes before they are applied.

## 💡 How It Works

```text
Folder
  ↓
Find files
  ↓
Filter supported files
  ↓
Generate new names
  ↓
Preview changes
  ↓
Confirm
  ↓
Rename files
  ↓
Show summary
